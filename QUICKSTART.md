# Quick Start Guide

Get up and running in 5 minutes!

## 1. Install Dependencies

```bash
npm install
```

## 2. Start Development Servers

```bash
npm run dev
```

This starts:
- **Backend** on http://localhost:3000
- **Frontend** on http://localhost:5173

## 3. Generate Your First QR Code

1. Open http://localhost:5173 in your browser
2. Enter a URL (e.g., `https://example.com`)
3. Choose a style and customize colors
4. Click "Generate QR Code"
5. Download or share your QR code!

## 4. Test the Redirect

1. Copy the "Share URL" from your generated QR code
2. Open it in a new tab
3. You'll be automatically redirected to the original URL
